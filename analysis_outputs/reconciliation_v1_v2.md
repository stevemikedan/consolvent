# HCCDE Reconciliation: v1 vs v2

## Overview
This report reconciles findings from v1 (100 episodes, exploratory) and v2 (1000 episodes, confirmatory).

> [!NOTE]
> **Only v2 is used for population-level inference.**

## Key Findings

### What HCCDE Theory Claims
- **Population-level bias**: The model predicts that baseline conditions will show a *trend* toward faster futures compared to controls
- **No per-seed guarantees**: Theory does NOT require every seed to show strong acceleration
- **Control expectations**: No-evolution, random-evolution, and high-decay conditions should show no systematic trend

### v1 Exploratory Results
- **Baseline median slope**: 0.1786
- **Assessment**: Short time horizons (100 episodes) led to noisy results with mixed seed-level outcomes
- **Role**: Exploratory sanity check only

### v2 Confirmatory Results
- **Baseline median slope**: 0.0218
- **Population trend detected**: False
- **Trend strength**: weak
- **Controls behaving as expected**: 3/3
